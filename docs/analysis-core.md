# Analysis Core и контур качества

**Владелец:** Михаил.  
**Статус:** рабочая промежуточная версия, получена из ветки `quality-core`
3 сентября 2026 года.

## Что реализовано

- гибридный review pipeline: LLM-проверки и детерминированный слой;
- таксономия дефектов и сокращённый prompt-вариант;
- шаблон документа и глоссарий;
- генератор воспроизводимого синтетического корпуса;
- эталонная разметка и scoring полноты;
- пять синтетических документов из разных предметных областей;
- автоматические тесты формальных проверок, review pipeline и scoring.

Основные команды:

```powershell
python generate.py --out data/synth
python run_review.py --help
python check_formal.py --help
python score.py --batch data/synth results
```

## Измерительный набор

Текущий synthetic golden set содержит 5 документов, 65 заранее внесённых дефектов
25 типов: 40 дефектов присутствия, 21 отсутствия содержания и 4 полностью удалённых
раздела. Пять типов проверяются детерминированно без LLM. Документ `synth_3`
намеренно почти чистый и служит негативным контролем.

Эталон создаётся до рендера документа: мутации вносятся в дерево узлов и сами
формируют truth-запись. Это уменьшает субъективность последующей ручной разметки.

## Предварительные результаты

В документации контура зафиксирована точность 83% на слепой внутренней разметке и
58% на внешней разметке кейсодателя. Эти значения являются промежуточными: методика,
объём выборок и итоговые метрики должны быть повторно зафиксированы перед защитой.
Главная следующая проверка — Recall@20 на synthetic golden set вместе с контролем
ложных срабатываний на чистых документах.

## Ограничения

- корпус синтетический и не заменяет оценку кейсодателем;
- для отсутствующего содержания применяется сопоставление по контейнеру, а не по
  невозможной дословной цитате;
- извлечение гиперссылок из DOCX пока ограничивает оценку части типов дефектов;
- реальные документы, результаты с цитатами и VPN-конфигурация не коммитятся в
  публичный репозиторий.
