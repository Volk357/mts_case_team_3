# Совместимость Analysis Core и Product Application

| Analysis Core | ReviewResult | Product Application | Review Pack | Статус |
|---|---|---|---|---|
| `0.2.0` | `1.x` | `0.1.0` | `mts-net 0.2` | поддерживается |
| `0.2.0` | `2.x` и выше | `0.1.0` | любой | отклоняется до сохранения |

Приложение принимает minor-обновления схемы `1.x`, если результат проходит
актуальную JSON Schema и проверки инвариантов. Новая major-версия требует
согласованного обновления контракта, fixtures, ядра и приложения.

## Проверки на границе worker

Результат считается недоверенным до завершения всех проверок:

1. процесс завершился с exit code `0`;
2. output-файл существует, не является symlink, укладывается в лимит и содержит
   ровно один JSON object в UTF-8;
3. major-версия поддерживается;
4. объект валиден по `contracts/review-result.schema.json`;
5. `run_id`, PID процесса, SHA-256 документа и версия Review Pack совпадают с job;
6. число findings не превышает 20, а каждый finding содержит `location`, `quote`,
   `problem` и `clarification`;
7. идентификаторы findings уникальны;
8. summary точно соответствует findings, а счётчики кандидатов непротиворечивы.

При нарушении результат не дополняется, не обрезается и не нормализуется. Worker
переводит job в `failed`, сохраняет безопасный код ошибки и оставляет `raw_result`
пустым. Исправление формата выполняется в Analysis Core с обновлением версии и
контрактных fixtures.
