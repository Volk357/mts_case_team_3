# Сквозная проверка настоящего Analysis Core

## Что проверяется

Интеграционный профиль `apps/api/tests/test_real_core_e2e.py` воспроизводит полный
пользовательский сценарий без обращения к внешней модели:

1. загружает валидный DOCX через HTTP API;
2. создаёт асинхронную проверку;
3. запускает установленный `docreview` отдельным процессом через worker;
4. принимает результат по JSON Schema и сохраняет все замечания;
5. читает статус и полный список замечаний через публичный API;
6. сохраняет и повторно читает обратную связь аналитика;
7. имитирует недоступность модели, проверяет retriable-ошибку и успешный ручной повтор.

Локальный HTTP-стаб заменяет только ответ модели. Парсер DOCX, Review Pack,
детерминированные правила, CLI-контракт, отдельный процесс, worker, база и API — настоящие.
Так тест остаётся воспроизводимым без WireGuard и GPU.

## Запуск

После `npm run setup`:

```powershell
apps/api/.venv/Scripts/python.exe -m pytest apps/api/tests/test_real_core_e2e.py -q
```

Если `docreview` не установлен в окружение API, тест явно пропускается. Обычный mock
остаётся тестовым и резервным адаптером; этот профиль всегда выбирает установленный
real core по абсолютному пути.

Переход интерфейса со страницы retriable-ошибки на новую страницу проверки закреплён
отдельным frontend-тестом `apps/web/src/test/review-page-retry.test.tsx`.
