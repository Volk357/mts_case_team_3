# Доказательная база двух замеров 7 сентября 2026

Оба замера цитируются в материалах сдачи, поэтому артефакты и команды
пересчёта лежат здесь, а не только в тексте.

## 1. Полнота под контрактным потолком — offline replay

**Что утверждается:** заголовочные 89%/78% сняты на выдаче в 105 замечаний,
то есть 21 на документ при потолке 20. Под потолком, то есть в той выдаче,
которую видит человек, полнота **83% по месту / 72% по типу** (96 замечаний).
Слой правил при отсечении не теряет ничего: 96%.

```bash
python3 evidence/2026-09-07/replay_capped.py --out /tmp/capped
python3 score.py --batch data/synth /tmp/capped --suffix _full2
```

Результат в `capped-run/` побайтово воспроизводится этой командой.

⚠️ **Граница метода, произносить вслух:** это offline replay зафиксированного
пула кандидатов, а не новый боевой прогон. Модель заново не вызывается,
поэтому её вариативность (±1 дефект между прогонами) здесь не воспроизводится.
Корректное утверждение: *на том же пуле кандидатов отсечение по бюджету
стоит 6 пунктов полноты*.

## 2. Цена резервной модели

**Что утверждается:** при отказе основной модели полнота падает
с 89%/78% до **75%/65%**, слой модели с 84% до 61%, **слой правил
не меняется — 96%**, потому что модель не использует.

```bash
python3 score.py --batch data/synth evidence/2026-09-07/fallback-run --suffix _full2
```

`fallback-run/` — выдача слоя модели, снятая через резервный эндпоинт
(`DOCREVIEW_FORCE_FALLBACK=1`, модель `qwen/qwen3.8-27b`, режим `full2`,
пакет `mts-net/0.2`). Слой правил модель не использует, поэтому при подсчёте
подкладывается тот же `formal/`, что и в основном прогоне, — скопируйте его:

```bash
cp -r data/ab_taxonomy/outputs/formal evidence/2026-09-07/fallback-run/
```

⚠️ **Границы:** один прогон на условие, разброс не измерялся. Выбор модели
резерва сделан по доступности, а не по качеству: серия из 6 запросов дала
`qwen3.8-27b` 6/6, `qwen3.7-flash` 5/6, `qwen3.8-max` 0/6, а исходная
кандидатура `qwen3.8-flash` — 2/6 (провайдер ограничивал частоту).

⚠️ **Резерв — внешний облачный сервис.** На 7 сентября он **выключен**
в конфигурации сервера: требование кейса — закрытый контур, а при
срабатывании резерва фрагменты документа покидают периметр. Замер сохранён
как ответ на вопрос «что будет, если основная модель отвалится», а не как
рабочий режим.

## Что этими артефактами НЕ доказывается

- полезность замечаний для аналитика (разметки нет);
- перенос на реальные документы заказчика (эталон синтетический, наш);
- стабильность цифр между прогонами для резерва и для capped-replay.
