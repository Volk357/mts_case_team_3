# 01. Каркас проекта

## Цель

Создать минимальную, воспроизводимую структуру Product Application, не связанную с внутренним кодом Analysis Core.

## Зависимости

- решение по стеку;
- корневая структура репозитория;
- базовая версия интеграционного контракта.

## Последовательность работ

### NIK-01-01. Backend workspace

**Статус:** выполнено 3 сентября 2026 года.

- создать `apps/api`;
- настроить Python-проект и lock-файл;
- подключить FastAPI и Pydantic;
- добавить конфигурацию окружения;
- создать `/api/health`;
- разделить API, services, repositories и workers;
- настроить pytest, линтер и type checking.

### NIK-01-02. Frontend workspace

**Статус:** выполнено 3 сентября 2026 года.

- создать `apps/web` на React, TypeScript и Vite;
- подключить Tailwind и библиотеку компонентов;
- настроить маршрутизацию;
- добавить API client;
- добавить unit tests и lint;
- создать health/debug страницу.

### NIK-01-03. Общие контракты

**Статус:** выполнено 3 сентября 2026 года.

- разместить JSON Schema в `contracts`;
- настроить генерацию TypeScript-типов;
- использовать сгенерированные типы в API client;
- запретить независимое ручное описание `Finding` на frontend.

### NIK-01-04. Конфигурация

**Статус:** выполнено 3 сентября 2026 года.

- добавить `.env.example`;
- разделить development, test и demo настройки;
- определить директории документов и запусков;
- настроить допустимые CORS origins;
- не хранить реальные API keys в репозитории.

### NIK-01-05. Developer experience

**Статус:** выполнено 3 сентября 2026 года.

- добавить команды установки и запуска;
- добавить pre-commit или единый check script;
- настроить `.gitignore`;
- описать структуру в README;
- добавить минимальный CI: lint, typecheck, tests, build.

## Артефакты

- запускаемый FastAPI;
- запускаемый React frontend;
- общий контракт типов;
- `.env.example`;
- CI workflow;
- инструкция разработчика.

## Проверки

- чистая установка проходит по README;
- backend tests проходят;
- frontend tests и build проходят;
- frontend успешно вызывает `/api/health`;
- секреты и runtime-файлы игнорируются Git.

## Критерий завершения

На чистом окружении frontend и backend запускаются, взаимодействуют через health endpoint и проходят автоматические проверки.
