# 04. Загрузка файлов

## Цель

Безопасно принять пользовательский PDF/DOCX, сохранить его и передать Analysis Core по внутреннему пути.

## Зависимости

- модель `Document`;
- настроенная директория хранения;
- ограничения допустимых форматов и размера.

## Последовательность работ

### NIK-04-01. Upload endpoint

**Статус:** выполнено 3 сентября 2026 года.

- реализовать `POST /api/documents`;
- принимать multipart upload;
- поддержать PDF и DOCX;
- возвращать `document_id`, имя, размер и media type;
- не возвращать внутренний путь.

### NIK-04-02. Валидация

**Статус:** выполнено 3 сентября 2026 года.

- ограничить размер конфигурацией;
- проверить расширение и фактический формат;
- отклонить пустой файл;
- нормализовать отображаемое имя;
- не использовать пользовательское имя как имя на диске;
- запретить path traversal.

### NIK-04-03. Сохранение

**Статус:** выполнено 3 сентября 2026 года.

- писать файл потоково;
- использовать временный файл;
- вычислять SHA-256;
- атомарно перемещать файл в постоянное место;
- удалить временный файл при ошибке;
- создать запись `Document` только после успешной записи.

### NIK-04-04. Защита и эксплуатация

**Статус:** выполнено 3 сентября 2026 года.

- предусмотреть точку подключения antivirus scan;
- установить безопасные filesystem permissions;
- не логировать содержимое документа;
- очищать orphaned uploads отдельной процедурой;
- добавить метрики размера и ошибок загрузки.

### NIK-04-05. UI загрузки

**Статус:** выполнено 3 сентября 2026 года.

- drag-and-drop;
- явные допустимые форматы;
- отображение размера;
- progress;
- возможность заменить выбранный файл;
- понятные ошибки размера и формата.

## Артефакты

- upload API;
- storage service;
- FileDropzone;
- тестовые PDF/DOCX;
- конфигурация ограничений.

## Проверки

- корректный PDF и DOCX принимаются;
- поддельное расширение отклоняется;
- слишком большой и пустой файл отклоняются;
- кириллица в имени отображается корректно;
- path traversal не влияет на путь хранения;
- оборванная загрузка не оставляет Document в БД.

## Критерий завершения

Пользователь загружает допустимый документ, приложение безопасно сохраняет его под внутренним ID и может передать абсолютный путь Job Runner.
