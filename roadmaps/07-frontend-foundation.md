# 07. Frontend-каркас

## Цель

Создать устойчивый пользовательский путь от выбора документа до ожидания результата.

## Зависимости

- OpenAPI/backend fixtures;
- upload и reviews endpoints;
- доступные Review Packs;
- UI-направление продукта.

## Последовательность работ

### NIK-07-01. Архитектура frontend

- настроить routing;
- создать API client;
- использовать сгенерированные типы;
- определить query/state подход;
- создать общие layout, typography и colors;
- реализовать error boundary.

### NIK-07-02. Стартовая страница

- сформулировать назначение продукта;
- добавить FileDropzone;
- показать ограничения форматов и размера;
- добавить ReviewPackSelector;
- заблокировать запуск до валидного выбора;
- показать, что документ не переписывается автоматически.

### NIK-07-03. Upload flow

- загрузка с progress;
- отмена до submit;
- повтор после сетевой ошибки;
- отображение имени и размера;
- очистка формы после успешного создания review.

### NIK-07-04. Review progress

- маршрут `/reviews/{id}`;
- polling статуса;
- стадии `queued/running/completed/failed`;
- восстановление после reload;
- остановка polling в terminal state;
- понятный экран долгого анализа.

### NIK-07-05. Ошибочные состояния

- файл отклонён;
- Review Pack недоступен;
- ядро недоступно;
- модель недоступна;
- timeout;
- несовместимый результат;
- неизвестная ошибка с correlation ID.

### NIK-07-06. Доступность и адаптивность

- управление с клавиатуры;
- видимый focus;
- контраст;
- aria labels;
- рабочая ширина ноутбука и демонстрационного экрана;
- отсутствие layout shift на progress.

## Артефакты

- стартовая страница;
- upload flow;
- ReviewPackSelector;
- ReviewProgress;
- error states;
- frontend tests.

## Проверки

- happy path работает на mock backend;
- reload не теряет review;
- polling прекращается;
- double click не создаёт два review;
- все error fixtures отображаются понятно;
- интерфейс проходим с клавиатуры.

## Критерий завершения

Пользователь может загрузить документ, запустить проверку, наблюдать состояние и попасть на результат без ручного обновления.
