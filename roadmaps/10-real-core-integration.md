# 10. Интеграция настоящего Analysis Core

## Цель

Заменить mock CLI на поставку Михаила без изменения пользовательского сценария, API и frontend.

## Зависимости

- стабильный Product Application на mock;
- устанавливаемая версия `docreview`;
- совместимая JSON Schema;
- готовый Review Pack;
- доступный model endpoint.

## Последовательность работ

### NIK-10-01. Приём поставки

- зафиксировать версию Analysis Core;
- выполнить `docreview version`;
- установить в worker environment;
- проверить доступность Review Pack;
- проверить model configuration и secrets;
- не копировать внутренний код ядра в backend.

### NIK-10-02. Smoke tests CLI

- запустить PDF напрямую;
- запустить DOCX напрямую;
- проверить stdout/stderr;
- проверить output file;
- проверить UTF-8;
- проверить exit codes;
- сохранить эталонные диагностические артефакты.

### NIK-10-03. Подключение Runner

- заменить executable path через конфигурацию;
- передать рабочую директорию;
- передать Review Pack и model config;
- проверить timeout реального анализа;
- ограничить объём stderr;
- корректно показать долгий running status.

### NIK-10-04. Контрактная проверка

- валидировать результат по JSON Schema;
- сверить `run_id`;
- проверить major schema version;
- проверить максимум 20 findings;
- проверить уникальность finding IDs;
- проверить обязательные location/quote/clarification;
- не исправлять невалидный результат на стороне приложения.

### NIK-10-05. End-to-end

- upload реального документа;
- запуск настоящего ядра;
- сохранение результата;
- отображение всех findings;
- переход к страницам;
- feedback;
- повтор после retriable ошибки.

### NIK-10-06. Совместная отладка

- Никита предоставляет command, exit code, stderr и contract validation errors;
- Михаил исправляет смысл и формат внутри Analysis Core;
- изменения контракта проходят через версию и fixtures;
- приложение не добавляет специальные обходы для отдельных дефектов.

## Артефакты

- закреплённая версия Analysis Core;
- integration test profile;
- реальный end-to-end fixture;
- таблица совместимости core/schema/application;
- инструкция переключения mock/real.

## Проверки

- один файл даёт одинаковый JSON при прямом CLI и через backend;
- русские цитаты совпадают;
- модель недоступна отображается как retriable ошибка;
- timeout не оставляет вечный running;
- неизвестная schema major отклоняется;
- frontend не изменяется при переходе с mock.

## Критерий завершения

Полный пользовательский сценарий проходит с реальным Analysis Core, а mock остаётся доступным только как тестовый и резервный адаптер.
