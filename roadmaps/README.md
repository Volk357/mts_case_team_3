## Правило работы

Каждый roadmap считается закрытым только после выполнения его критерия завершения. Если критерий не выполняется, следующий этап может использовать mock или fixture, но не должен считать зависимость готовой.

При переносе задач в issue tracker рекомендуется сохранять идентификатор этапа, например `NIK-05-03` для третьей задачи Job Runner.
